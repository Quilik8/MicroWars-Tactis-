# Identidad visual — revisión de alcance

El plan vigente y autocontenido es [Campaña jugable, ejércitos e identidad](CAMPAIGN_IDENTITY_PLAN.md).

Corrige el primer estudio: catálogo completo de once identidades; seis posiciones principales actuales; UI neutral, no verde; imágenes condicionadas a una función; comandantes, veteranía, nombres y dificultad como parte de la jugabilidad.

El tablero `faction-direction.html` es una propuesta navegable, no una pantalla integrada en el juego. Los datos de propuesta están en `faction-identity.proposal.json` y `army-names.proposal.json`. El archivo `FACTION_ASSET_PROMPTS.md` contiene un único prompt para un eventual lote de seis bases de comandante; no hace falta generar esas imágenes para probar la campaña.
