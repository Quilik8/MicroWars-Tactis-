# Un único prompt — lote opcional de seis bases de comandante

**No es necesario generar imágenes ahora.** Primero se validará la campaña automática y la ficha de comandante con símbolos. Este encargo solo se usaría para dar un rostro de especie al ejército que se selecciona, se arriesga, sobrevive o se pierde. Las seis corresponden a las posiciones principales actuales; el registro completo contiene once identidades.

Una base se reutilizaría en ficha del ejército y resultado; no se pretende que cada ejército comparta la misma identidad individual. Nombre, insignia y matrícula persistentes distinguen individuos. Las cinco especies restantes tendrán su propio encargo cuando tengan un uso jugable definido.

Copiar el siguiente bloque completo como UNA solicitud. Las instrucciones de estilo se dan una sola vez.
